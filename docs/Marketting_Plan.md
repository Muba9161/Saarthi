# CREATE A VISUAL MARKETING PLAYBOOK FOR THE PROJECT

Analyze the existing project and create a **highly visual, modern, easy-to-understand Marketing Playbook PDF** for the marketing team.

The document should NOT be a technical report.

It should function as a **visual marketing blueprint** that tells the marketing team exactly:

> WHAT are we marketing?  
> WHO are we marketing to?  
> WHAT problem are we solving?  
> WHY should customers care?  
> WHAT makes us different?  
> WHAT should we say?  
> WHERE should we market?  
> WHAT content should we create?  
> WHAT should we sell?  
> WHAT should we test first?

The team should be able to understand the entire marketing direction by quickly scanning the PDF.

---

# IMPORTANT — ANALYZE FIRST

Before creating the PDF, inspect the project enough to understand:

- Product
- Main purpose
- Target users
- User roles
- Major customer-facing features
- Customer problems solved
- Key benefits
- Existing/planned pricing
- Monetization
- Marketplace/network effects if applicable
- Major differentiators
- Existing integrations that create customer value
- Current product maturity

Do NOT expose:

- Source code
- API keys
- Credentials
- Secrets
- Database details
- Private URLs
- Internal security mechanisms
- Detailed technical architecture
- Proprietary implementation details

This document is for **marketing**, not developers.

---

# DESIGN DIRECTION

Create a PDF that looks like a combination of:

**Startup Pitch Deck + Marketing Strategy Board + Brand Playbook + Product Brochure**

It should be:

- Modern
- Premium
- Visual
- Minimal
- Easy to scan
- Business-focused
- Highly structured
- Infographic-heavy

Use:

- Large typography
- Visual cards
- Icons
- Diagrams
- Funnels
- Customer personas
- Comparison visuals
- Roadmaps
- Callout boxes
- Visual matrices
- Charts where meaningful
- Short text blocks

Avoid large paragraphs.

Every page should communicate a clear marketing idea.

# VISUAL DESIGN RULES

The document must be **visual-first**.

Aim for approximately:

**70% visual / 30% text**

Use:

- Infographics
- Icons
- Cards
- Flowcharts
- Funnels
- Diagrams
- Personas
- Comparison visuals
- Roadmaps
- Matrices
- Highlight numbers
- Callout statements

Avoid:

- Long essays
- Dense technical tables
- Code
- Technical architecture
- Database diagrams
- Excessive text

Each page should have **ONE primary message**.

---

Otherwise create a professional visual direction appropriate for the product.

- Brand personality

- Visual language

- Typography direction
- Content style

Keep the visual language consistent throughout the PDF.

# FINAL QUALITY CHECK

Before producing the PDF, verify:

- Is the product clearly explained?
- Are target customers obvious?
- Are customer pain points clear?
- Are USPs genuine?
- Are features translated into benefits?
- Is the marketing message memorable?
- Can a marketer immediately understand what to advertise?
- Are there concrete content ideas?
- Are there concrete ad hooks?
- Are acquisition channels clear?
- Are revenue experiments actionable?
- Is the 30-day plan practical?
- Are KPIs defined?
- Is confidential technical information excluded?
- Is the document visually easy to scan?

# FINAL OUTPUT

Generate **ONE polished visual PDF Marketing Playbook**.

Target length:

**15–22 pages**

The document should feel like an internal **Marketing War Room / Go-To-Market Playbook**.

A new marketing team member should be able to open it and immediately understand:

> **WHAT WE SELL**

> **WHO WE SELL TO**

> **WHAT PROBLEM WE SOLVE**

> **WHY CUSTOMERS SHOULD CARE**

> **WHAT MAKES US DIFFERENT**

> **WHAT WE SHOULD ADVERTISE**

> **WHAT CONTENT WE SHOULD CREATE**

> **WHERE WE SHOULD MARKET**
